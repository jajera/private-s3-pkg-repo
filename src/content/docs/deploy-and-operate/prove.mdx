## Overview

`demo.sh prove` uses **SSM Run Command** (no SSH). On each probe it imports the
lab public key from `repos/gpg/lab-signing.asc` on the **local** package bucket,
runs `gpg --verify` on signed metadata (`repomd.xml.asc` / `InRelease`), then
installs with `repo_gpgcheck=1` (dnf) or `signed-by=` (apt). Ubuntu also runs
`apt-get update` with `Debug::Acquire::gpgv=1` so the verifier is visible.

Keep instance, gateway, and bucket Region matched. Package-level `gpgcheck`
stays off for the sample EPEL RPM; the lab guarantee is **repo metadata**
signing.

<Aside type="caution">
  Probes have <strong>no NAT</strong> — only the S3 gateway (and SSM) VPCEs.
  Default Amazon Linux / Ubuntu archive repos are unreachable and will hang or
  time out. After <code>prove</code>, use only the lab repo:

  ```bash
  # AL2023 — disable every other repo
  sudo dnf -y --disablerepo='*' --enablerepo=ps3p-lab list available
  sudo dnf -y --refresh --disablerepo='*' --enablerepo=ps3p-lab install PACKAGE

  # Ubuntu — prove removes /etc/apt/sources.list; only ps3p-lab remains
  sudo apt-get update
  sudo apt-get install -y PACKAGE
  ```

  Use <code>--refresh</code> (or <code>dnf clean metadata</code>) after a new
  publish so root’s cache picks up new packages. Slowness that looks like
  “waiting on the internet” usually means a default repo is still enabled.
</Aside>

## Verify

```bash frame="terminal"
jq '{
  packages: .packages,
  syd: {al2023: .consumers.syd.al2023.instance_id, ubuntu: .consumers.syd.ubuntu.instance_id},
  akl: {al2023: .consumers.akl.al2023.instance_id, ubuntu: .consumers.akl.ubuntu.instance_id}
}' .lab-state.json
```

<Aside type="note">
  A “not certified / untrusted key” warning from <code>gpg --verify</code> is
  expected for a freshly imported key without ownertrust.
  <code>GOODSIG</code> still means the signature matches the lab key. Apt trusts
  the key via <code>signed-by=</code> on the keyring file.
</Aside>

<Aside type="tip">
  Signed admin CLI from your laptop still works (bypass ARN). Package Get from
  the public internet should still be 403 after allowlist — installs are meant
  to go through the probes.
</Aside>
